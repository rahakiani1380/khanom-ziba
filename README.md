# خانوم زیبا — فروشگاه اینترنتی لوازم پزشکی و بهداشتی

فروشگاه دوزبانه (فارسی / English) با Node.js، Tailwind CSS و jQuery. بدون نیاز به `npm install`.

## امکانات
- صفحه اصلی، محصولات (دسته‌بندی درختی، برند، مرتب‌سازی)، صفحه محصول (گالری، مشخصات، نظر و ستاره)، سبد خرید، ورود با شماره موبایل، پروفایل و سفارش‌ها
- تخفیف‌های ویژه با تایمر معکوس، بنرهای چندتصویری، نوار اعلان، فوتر قابل ویرایش
- پنل ادمین (`/admin`) و بخش سئو (عنوان، توضیح، نقشه سایت، ریدایرکت، بررسی خودکار)

## اجرا روی کامپیوتر
```
node server.js
```
سایت: http://localhost:3000 — پنل ادمین: http://localhost:3000/admin

نام کاربری و رمز ادمین را با متغیرهای `ADMIN_USER` و `ADMIN_PASS` تعیین کنید. اگر تعیین نکنید، رمز پیش‌فرض `admin123` است و **فقط برای کامپیوتر خودتان مناسب است**.

## نسخه آزمایشی آنلاین
GitHub Pages فقط فایل‌های ثابت را نشان می‌دهد و سرور Node.js را اجرا نمی‌کند. برای نسخه زنده، همین مخزن را به یک سرویس میزبانی Node.js وصل کنید (مثلاً Render با فایل `render.yaml`).
در نسخه آزمایشی کد تأیید پیامک روی صفحه نشان داده می‌شود. شماره موبایل واقعی وارد نکنید (مثلاً 09120000000).

## ساختار
`server.js` سرور و API، `mini-express.js` سرور کوچک بدون وابستگی، `public/` صفحه‌های سایت و پنل، `data/products.json` محصولات نمونه.
داده‌های زنده (کاربران، سفارش‌ها) در `data/db.json` ذخیره می‌شود و عمداً در `.gitignore` است.
